MỤC ĐÍCH: Minh họa pipeline hoạt động đồng thời — tại C5 cả 5 lệnh đều
đang chạy ở các tầng khác nhau. Giải thích tại sao throughput tăng ~2.8×.

ASCII SƠ ĐỒ:

        C1    C2    C3    C4    C5    C6    C7    C8    C9
Lệnh1 [ IF ][ ID ][ EX ][MEM ][ WB ]
Lệnh2       [ IF ][ ID ][ EX ][MEM ][ WB ]
Lệnh3             [ IF ][ ID ][ EX ][MEM ][ WB ]
Lệnh4                   [ IF ][ ID ][ EX ][MEM ][ WB ]
Lệnh5                         [ IF ][ ID ][ EX ][MEM ][ WB ]
      ─────────────────────────────────────────────────────
       Tại C5: 5 lệnh chạy đồng thời ← đây là điểm cần highlight

  Single-cycle: 5 lệnh × 5 cycle = 25 cycles
  Pipeline    : 5 + (5-1)         =  9 cycles  → tăng 2.8×

  Màu ô: IF=xanh | ID=cam | EX=vàng | MEM=xanh lá | WB=tím

NHẬN XÉT:
  [MINOR] Nên thêm tên lệnh cụ thể: "ADD x1,x2,x3", "SUB x4,x5,x6"...
          thay vì chỉ "Lệnh 1", "Lệnh 2".

ASCII SƠ ĐỒ:

          C1    C2    C3    C4    C5    C6    C7    C8
lw x2,0(x1)
        [ IF ][ ID ][ EX ][MEM*][ WB ]
                              │
                              └── data x2 sẵn sàng sau MEM
add x3,x2,x1
              [ IF ][ ID ][NOP!][ EX ][ MEM][ WB ]
                            ↑     ↑
                         stall  fwd MEM→EX
sub x4,x5,x6
                    [ IF ][ ID ][ ID*][ EX ][ MEM][ WB ]
                                  ↑
                            giữ lại (stall propagation)

  NOP  = màu đỏ nhạt (hồng)
  MEM* = viền cam đậm (highlight nguồn forward)
  EX*  = viền cam đậm (highlight đích forward)
  Mũi tên forwarding: từ MEM[C4] → EX[C5], màu cam/đỏ

  [MINOR] Đồng nhất style mũi tên forwarding (dùng block arrow).

ASCII SƠ ĐỒ:

              C1    C2    C3    C4    C5    C6    C7    C8
BEQ x1,x2,L
            [ IF ][ ID ][ EX ][ MEM][ WB ]
                          ↑
                    branch resolved!
                    PC → L (target)
I+1: add
                  [ IF ][FLSH]  ← bị flush tại C3
I+2: sub
                        [FLSH]  ← bị flush tại C3
L: lw x9,0(x1)  ← lệnh tại địa chỉ target L
                              [ IF ][ ID ][ EX ][ MEM][ WB ]
                               ↑
                          fetch lại từ C4

  FLUSH = màu xám nhạt + chữ đỏ
  EX của BEQ = viền đỏ đậm (highlight điểm resolve)
  Annotation: "Branch taken! PC→L" ngay trên EX@C3
  Ghi chú cuối: "Branch Penalty = 2 cycles (Late Resolution tại EX stage)"
