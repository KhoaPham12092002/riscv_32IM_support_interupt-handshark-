## Vấn đề đã phát hiện và fix

### 1. IMEM không load hex file (critical)
- **Bug**: `imem.sv` có `parameter bit LOAD_HEX = 0` → `$readmemh` không bao giờ được gọi → CPU fetch toàn NOP.
- **Fix**: Đổi default thành `LOAD_HEX = 1`.

### 2. IMEM word array không khớp với hex file format (critical)
- **Bug**: `objcopy -O verilog` (không có `--verilog-data-width=4`) sinh file byte-per-element (`37 11 00 20 ...`). `$readmemh` vào `logic [31:0] mem_array` nạp `37` vào word[0] thay vì `0x20001137`.
- **Fix**: Đổi `mem_array` thành `logic [7:0] mem_array[0:MEM_SIZE-1]`; reconstruct 32-bit instruction bằng concatenation little-endian trong `always_comb`.

### 3. Harvard architecture — hex_map không thể ở IMEM (critical)
- **Bug**: Phiên bản cũ đặt bảng `hex_map` trong section `.text` (IMEM). LSU không route địa chỉ `0x0000_xxxx` → `lbu` từ IMEM treo CPU mãi (không có `rsp_valid` từ DMEM).
- **Fix**: Bỏ `.rodata` hex_map. Trong `_init`, dùng `li` + `sb` để khởi tạo 10 byte vào DMEM `0x2000_0000..0x2000_0009`. Thanh ghi `x30` giữ cố định base address DMEM trong toàn bộ vòng lặp.

### 4. UART tx_wait loop sai chiều (bug logic)
- **Bug**: Code cũ dùng `beqz x7, tx_wait` → loop khi UART **không** busy → ghi TX_DATA ngay lập tức mà không chờ.
- **Fix**: Đổi thành `bnez x7, tx_wait` → loop **khi** tx_busy=1, thoát khi tx_busy=0, rồi mới ghi TX_DATA.

### 5. Address decoder Cấp 2 — periph_addr_t sai kích thước
- **Bug**: `periph_addr_t` cũ là 16-bit ID (không phải địa chỉ thực). Decoder Cấp 2 không cast đúng.
- **Fix**: Định nghĩa lại thành 20-bit page offset (`ADDR_SW_LED=20'h00000`, `ADDR_HEX=20'h01000`, ...). Decoder dùng `periph_addr_t'(io_addr_i & 20'hFF000)`.

## Kiến trúc quan trọng cần nhớ

```
Harvard SoC:
  IMEM  0x0000_0000  →  PC fetch only (không dùng LSU)
  DMEM  0x2000_0000  →  LOAD/STORE (LSU route)
  IO    0x4000_0000  →  LOAD/STORE (LSU route)

IO Cấp 2 (address_decoder):
  0x4000_0000  SW_LED   Read: SW[9:0]   Write: LED[9:0]
  0x4000_1000  HEX      Write: raw 7-seg code → hex_reg[0..5][6:0]
  0x4000_2000  KEY      Read: KEY[3:0] active-low
  0x4000_3000  UART     +0=TX +4=RX +8=STATUS +C=CTRL
  0x4000_4000  GPIO     +0=DATA +4=DIR

programv2.s modes (SW[1:0]):
  00  HEX hiển thị N² (N = SW[9:2])
  01  Gửi SW[9:2] dạng 2 ký tự HEX ASCII qua UART TX
  10  Echo UART RX → TX
  11  Không định nghĩa → về main_loop
```
